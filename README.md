# Damarkandang

Sistem manajemen cafe Damarkandang: bahan, stok, penjualan (kasir), keuangan, dan laporan.

## Menjalankan

1. Salin `.env` (MongoDB URI, `DB_NAME=DB_DAMARKANDANG`, `SECRET_KEY`).
2. Install dependensi Python, lalu jalankan:

```bash
python app.py
```

Buka `http://127.0.0.1:5003` lalu pilih peran Admin, Owner, atau Karyawan.
